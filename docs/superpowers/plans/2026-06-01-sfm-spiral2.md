# SfM Spiral 2 Implementation Plan — Custom SIFT Detector

> **Goal:** Learn SIFT detection by implementing it from scratch — Gaussian pyramid, DoG,
> keypoint localization. Replace `CvSiftDetector` with our own `SiftDetector` in the pipeline.

**Architecture:** `SiftDetector` implements `IFeatureDetector` using three internal stages:
`GaussianPyramid` → `DifferenceOfGaussians` → `KeypointLocalizer`. Each stage is independently
testable. The detector swaps seamlessly into the existing `SiftPipeline`.

**Tech Stack:** C++17, OpenCV (image I/O, `cv::Mat`, `cv::GaussianBlur`, `cv::resize`), Catch2


Spiral 2 swaps exactly one box:

## Algorithm Overview

```
Input Image (grayscale)
    │
    ▼
GaussianPyramid
    │  Build octaves: each octave = progressively σ-blurred images
    │  Between octaves: downsample ×2
    │  Typically: 4 octaves, 5 scales/octave, σ₀ = 1.6
    ▼
DifferenceOfGaussians
    │  D(x,y,σ) = L(x,y,kσ) - L(x,y,σ)   for each adjacent scale pair
    │  Approximates scale-normalized Laplacian of Gaussian
    ▼
KeypointLocalizer
    │  1. Extrema detection: 3×3×3 neighborhood, keep local max/min
    │  2. Subpixel refinement: 3D quadratic fit (Taylor), reject if |offset| > 0.5
    │  3. Edge suppression: Hessian trace²/det ratio, reject if > threshold
    ▼
std::vector<KeyPoint>
```

### Task 1: Gaussian Pyramid

Build the scale-space pyramid. This is the foundation — everything else depends on it.

**What it does:**
- Given a grayscale image, produce `n_octaves` octaves
- Each octave contains `n_scales + 3` blurred images at increasing σ
- σ progression: σ₀, kσ₀, k²σ₀, ..., k^(s+2)σ₀ where k = 2^(1/s)
- Between octaves, the image is downsampled by 2

**Parameters:**
- `n_octaves` = typically `floor(log2(min(w,h)) - 3)`
- `n_scales` = 3 (intervals per octave, s=3 → k=2^(1/3)≈1.26)
- `sigma0` = 1.6

**Files:**

```cpp
#include <opencv2/core/mat.hpp>
#include <vector>

namespace meow::sfm {

struct PyramidOctave {
  std::vector<cv::Mat> scales;  // blurred images at increasing σ
};

struct GaussianPyramid {
  std::vector<PyramidOctave> octaves;
  double sigma0;   // base sigma
  int n_scales;     // intervals per octave
};

/// Build a Gaussian scale-space pyramid.

/// @param n_octaves  number of octaves (auto-computed if 0)

/// @param sigma0     initial sigma (default 1.6)
GaussianPyramid build_gaussian_pyramid(
    const cv::Mat& image,
    int n_octaves = 0,
    int n_scales = 3,
    double sigma0 = 1.6);

}  // namespace meow::sfm
```

```cpp
// sfm/src/features/sift/gaussian_pyramid.cpp
#include <sfm/features/sift/gaussian_pyramid.h>

#include <opencv2/imgproc.hpp>
#include <cassert>
#include <cmath>

namespace meow::sfm {

GaussianPyramid build_gaussian_pyramid(
    const cv::Mat& image,
    int n_octaves,
    int n_scales,
    double sigma0) {

  assert(!image.empty());
  assert(image.type() == CV_8UC1);
  assert(n_scales >= 1);
  assert(sigma0 > 0.0);

  if (n_octaves <= 0) {
    // Auto-compute: maximum number of octaves such that the smallest
    // image is at least 8×8 pixels
    n_octaves = static_cast<int>(
        std::floor(std::log2(std::min(image.cols, image.rows))) - 3);
    if (n_octaves < 1) n_octaves = 1;
  }

  const double k = std::pow(2.0, 1.0 / n_scales);
  // We need n_scales + 3 blurred images per octave to produce
  // n_scales + 2 DoG images, which gives us n_scales usable DoG
  // levels for extrema detection (3×3×3 neighborhood).
  const int n_images = n_scales + 3;

  GaussianPyramid pyramid;
  pyramid.sigma0 = sigma0;
  pyramid.n_scales = n_scales;
  pyramid.octaves.resize(n_octaves);

  // Convert to float for precision in Gaussian convolution
  cv::Mat current;
  image.convertTo(current, CV_32F, 1.0 / 255.0);

  for (int o = 0; o < n_octaves; ++o) {
    auto& octave = pyramid.octaves[o];
    octave.scales.resize(n_images);

    // Pre-blur the first image of this octave if octave > 0
    if (o == 0) {
      // Double the image size for more keypoints (Lowe)
      cv::resize(current, current, cv::Size(current.cols * 2, current.rows * 2),
                 0, 0, cv::INTER_LINEAR);
      // Blur to sigma0 (assume input has nominal blur of 0.5)
      double sigma_prev = 0.5;
      double sigma_blur = std::sqrt(sigma0 * sigma0 - sigma_prev * sigma_prev);
      if (sigma_blur > 0.0) {
        cv::GaussianBlur(current, current, cv::Size(0, 0), sigma_blur, sigma_blur);
      }
    }

    for (int s = 0; s < n_images; ++s) {
      if (s == 0 && o == 0) {
        // First image: already blurred to sigma0
        octave.scales[s] = current.clone();
      } else if (s == 0) {
        // First image of subsequent octave: downsample from previous octave
        cv::resize(current, current, cv::Size(current.cols / 2, current.rows / 2),
                   0, 0, cv::INTER_NEAREST);
        octave.scales[s] = current.clone();
      } else {
        // Blur the previous scale
        double sig_prev = sigma0 * std::pow(k, s - 1);
        double sig_curr = sigma0 * std::pow(k, s);
        double sig_diff = std::sqrt(sig_curr * sig_curr - sig_prev * sig_prev);
        cv::GaussianBlur(octave.scales[s - 1], octave.scales[s],
                         cv::Size(0, 0), sig_diff, sig_diff);
      }
    }

    // Prepare current for next octave: use the 3rd-from-last scale
    // (scale at 2*sigma0 in this octave, becomes sigma0 when downsampled)
    int src_idx = n_images - 3;  // = n_scales
    current = octave.scales[src_idx].clone();
  }

  return pyramid;
}

}  // namespace meow::sfm
```

### Task 2: Difference of Gaussians

Subtract adjacent blurred images within each octave to produce DoG.

**Why DoG:**
DoG approximates the scale-normalized Laplacian of Gaussian (LoG), which produces
maximal responses at blob-like structures of the corresponding scale. It's efficient:
just subtract adjacent Gaussian-blurred images.

```cpp
// sfm/src/features/sift/dog.cpp
#include <sfm/features/sift/dog.h>

#include <cassert>

namespace meow::sfm {

DogPyramid build_dog_pyramid(const GaussianPyramid& gauss_pyr) {
  DogPyramid dog;
  dog.sigma0 = gauss_pyr.sigma0;
  dog.n_scales = gauss_pyr.n_scales;
  dog.octaves.resize(gauss_pyr.octaves.size());

  for (size_t o = 0; o < gauss_pyr.octaves.size(); ++o) {
    const auto& src = gauss_pyr.octaves[o].scales;
    const int n_dog = static_cast<int>(src.size()) - 1;
    dog.octaves[o].resize(n_dog);

    for (int s = 0; s < n_dog; ++s) {
      cv::subtract(src[s + 1], src[s], dog.octaves[o][s]);
      // Keep absolute values? No — extrema detection works on signed values.
      // Negative DoG = dark blob, Positive DoG = bright blob.
    }
  }

  return dog;
}

}  // namespace meow::sfm
```

### Task 3: Keypoint Localizer

Find extrema in the DoG pyramid, refine to subpixel accuracy, reject edges.

**Three sub-steps:**
1. **Extrema detection** — scan each DoG image's interior (skip border). A pixel is an
   extremum if it's > all 26 neighbors in the 3×3×3 cube (or < all 26 for minima).
2. **Subpixel refinement** — fit a 3D quadratic to the DoG values around the extremum
   using Taylor expansion. Solve for the offset. Reject if |offset| > 0.5 in any
   dimension (peak is closer to a different sample point).
3. **Edge suppression** — compute the 2×2 Hessian at the keypoint. Reject if
   trace²/det > (r+1)²/r where r=10 (Lowe's threshold), since edges have high
   principal curvature ratio.

**Files:**
- Create: `sfm/include/sfm/features/sift/keypoint_localizer.h`
- Create: `sfm/src/features/sift/keypoint_localizer.cpp`
- Create: `sfm/tests/test_keypoint_localizer.cpp`

```cpp
// sfm/src/features/sift/keypoint_localizer.cpp
#include <sfm/features/sift/keypoint_localizer.h>

#include <cassert>
#include <cmath>

namespace meow::sfm {

namespace {

/// Check if (row,col,scale) is a local extremum in the 3×3×3 neighborhood.
bool is_extremum(const std::vector<cv::Mat>& dog_octave, int s, int r, int c) {
  double val = dog_octave[s].at<float>(r, c);

  // Check against all 26 neighbors
  bool is_max = true, is_min = true;
  for (int ds = -1; ds <= 1; ++ds) {
    for (int dr = -1; dr <= 1; ++dr) {
      for (int dc = -1; dc <= 1; ++dc) {
        if (ds == 0 && dr == 0 && dc == 0) continue;
        double nb = dog_octave[s + ds].at<float>(r + dr, c + dc);
        if (val <= nb) is_max = false;
        if (val >= nb) is_min = false;
      }
    }
  }
  return is_max || is_min;
}

/// Compute 3D quadratic Taylor expansion offset at (s,r,c).
/// Solves: H * offset = -grad  →  offset = -H⁻¹ * grad
/// Returns true if converged, fills dx, dy, ds.
bool taylor_refine(const std::vector<cv::Mat>& dog_octave,
                   int s, int r, int c,
                   double& dx, double& dy, double& ds) {
  // First derivatives (centered differences)
  double dD_dx = (dog_octave[s].at<float>(r, c + 1) -
                  dog_octave[s].at<float>(r, c - 1)) * 0.5;
  double dD_dy = (dog_octave[s].at<float>(r + 1, c) -
                  dog_octave[s].at<float>(r - 1, c)) * 0.5;
  double dD_ds = (dog_octave[s + 1].at<float>(r, c) -
                  dog_octave[s - 1].at<float>(r, c)) * 0.5;

  // Second derivatives
  double d2D_dx2 = dog_octave[s].at<float>(r, c + 1) +
                   dog_octave[s].at<float>(r, c - 1) -
                   2.0 * dog_octave[s].at<float>(r, c);
  double d2D_dy2 = dog_octave[s].at<float>(r + 1, c) +
                   dog_octave[s].at<float>(r - 1, c) -
                   2.0 * dog_octave[s].at<float>(r, c);
  double d2D_ds2 = dog_octave[s + 1].at<float>(r, c) +
                   dog_octave[s - 1].at<float>(r, c) -
                   2.0 * dog_octave[s].at<float>(r, c);

  // Cross derivatives
  double d2D_dxdy = (dog_octave[s].at<float>(r + 1, c + 1) -
                     dog_octave[s].at<float>(r + 1, c - 1) -
                     dog_octave[s].at<float>(r - 1, c + 1) +
                     dog_octave[s].at<float>(r - 1, c - 1)) * 0.25;
  double d2D_dxds = (dog_octave[s + 1].at<float>(r, c + 1) -
                     dog_octave[s + 1].at<float>(r, c - 1) -
                     dog_octave[s - 1].at<float>(r, c + 1) +
                     dog_octave[s - 1].at<float>(r, c - 1)) * 0.25;
  double d2D_dyds = (dog_octave[s + 1].at<float>(r + 1, c) -
                     dog_octave[s + 1].at<float>(r - 1, c) -
                     dog_octave[s - 1].at<float>(r + 1, c) +
                     dog_octave[s - 1].at<float>(r - 1, c)) * 0.25;

  // Hessian H = [dxx dxy dxs; dxy dyy dys; dxs dys dss]
  // Solve H * x = -g using Cramer's rule
  double detH = d2D_dx2 * (d2D_dy2 * d2D_ds2 - d2D_dyds * d2D_dyds)
              - d2D_dxdy * (d2D_dxdy * d2D_ds2 - d2D_dyds * d2D_dxds)
              + d2D_dxds * (d2D_dxdy * d2D_dyds - d2D_dy2 * d2D_dxds);

  if (std::abs(detH) < 1e-12) return false;

  double inv_det = 1.0 / detH;
  dx = -inv_det * (
      dD_dx * (d2D_dy2 * d2D_ds2 - d2D_dyds * d2D_dyds)
    - dD_dy * (d2D_dxdy * d2D_ds2 - d2D_dyds * d2D_dxds)
    + dD_ds * (d2D_dxdy * d2D_dyds - d2D_dy2 * d2D_dxds));

  dy = -inv_det * (
      dD_dx * (d2D_dxdy * d2D_ds2 - d2D_dyds * d2D_dxds) * (-1.0)  // sign from cofactor
    + dD_dy * (d2D_dx2 * d2D_ds2 - d2D_dxds * d2D_dxds) * (1.0)
    - dD_ds * (d2D_dx2 * d2D_dyds - d2D_dxdy * d2D_dxds));

  // Actually let me redo this more carefully with the proper cofactor signs
  // detH = dxx*(dyy*dss - dys*dys) - dxy*(dxy*dss - dys*dxs) + dxs*(dxy*dys - dyy*dxs)
  // H⁻¹ = (1/detH) * adj(H),  adj(H)[i,j] = (-1)^(i+j) * det(minor[j,i])
  // offset = -H⁻¹ * grad

  // Let's solve directly instead of Cramer for clarity:
  // H * x = -g   where H is 3×3, g is 3×1
  // Use Gauss elimination on the 3×3 system

  double a11 = d2D_dx2,  a12 = d2D_dxdy, a13 = d2D_dxds;
  double a21 = d2D_dxdy, a22 = d2D_dy2,  a23 = d2D_dyds;
  double a31 = d2D_dxds, a32 = d2D_dyds, a33 = d2D_ds2;

  double b1 = -dD_dx, b2 = -dD_dy, b3 = -dD_ds;

  // Forward elimination
  // Normalize row 1
  double f = a11;
  if (std::abs(f) < 1e-12) return false;
  double r12 = a12 / f, r13 = a13 / f, r1b = b1 / f;

  // Eliminate from row 2
  f = a22 - a21 * r12;
  if (std::abs(f) < 1e-12) return false;
  double r23 = (a23 - a21 * r13) / f;
  double r2b = (b2 - a21 * r1b) / f;

  // Eliminate from row 3
  f = a33 - a31 * r13 - (a32 - a31 * r12) * r23;
  if (std::abs(f) < 1e-12) return false;
  double r3b = (b3 - a31 * r1b - (a32 - a31 * r12) * r2b) / f;

  ds = r3b;
  dy = r2b - r23 * ds;
  dx = r1b - r12 * dy - r13 * ds;

  return true;
}

/// Edge suppression: reject points with high principal curvature ratio.
/// Uses the 2×2 Hessian of the DoG. Rejects if trace²/det > (r+1)²/r.
bool is_edge(const std::vector<cv::Mat>& dog_octave, int row, int col, int s,
             double edge_ratio_thresh) {
  double dxx = dog_octave[s].at<float>(row, col + 1) +
               dog_octave[s].at<float>(row, col - 1) -
               2.0 * dog_octave[s].at<float>(row, col);
  double dyy = dog_octave[s].at<float>(row + 1, col) +
               dog_octave[s].at<float>(row - 1, col) -
               2.0 * dog_octave[s].at<float>(row, col);
  double dxy = (dog_octave[s].at<float>(row + 1, col + 1) -
                dog_octave[s].at<float>(row + 1, col - 1) -
                dog_octave[s].at<float>(row - 1, col + 1) +
                dog_octave[s].at<float>(row - 1, col - 1)) * 0.25;

  double trace = dxx + dyy;
  double det = dxx * dyy - dxy * dxy;

  if (det <= 0.0) return true;  // negative determinant → saddle → edge

  double r = edge_ratio_thresh;
  double thresh = (r + 1.0) * (r + 1.0) / r;
  return (trace * trace / det) > thresh;
}

/// Convert octave/scale/row/col to input-image coordinates.
/// Undoes the 2× upsampling of octave 0 and octave downsampling.
void octave_to_image_coords(int octave, int scale_idx,
                            double row, double col,
                            double sigma0, int n_scales,
                            double& img_x, double& img_y,
                            double& sigma) {
  // Scale factor: octave 0 is 2× upsampled, octave 1 is original, etc.
  // So octave 0 → divide by 2, octave 1 → multiply by 1, octave 2 → multiply by 2
  double scale_factor = std::pow(2.0, octave - 1);
  img_x = col * scale_factor;
  img_y = row * scale_factor;

  double k = std::pow(2.0, 1.0 / n_scales);
  sigma = sigma0 * std::pow(k, scale_idx) * std::pow(2.0, octave - 1);
}

}  // namespace

std::vector<KeyPoint> localize_keypoints(const DogPyramid& dog,
                                         const LocalizerParams& params) {
  std::vector<KeyPoint> keypoints;

  for (size_t o = 0; o < dog.octaves.size(); ++o) {
    const auto& oct = dog.octaves[o];
    // We need s ∈ [1, n_scales] for 3×3×3 neighborhood
    // Dog has n_scales+2 images, indexed 0..n_scales+1
    for (int s = 1; s < static_cast<int>(oct.size()) - 1; ++s) {
      for (int r = 1; r < oct[s].rows - 1; ++r) {
        for (int c = 1; c < oct[s].cols - 1; ++c) {

          if (!is_extremum(oct, s, r, c)) continue;

          // Subpixel refinement
          double dx = 0.0, dy = 0.0, ds = 0.0;
          if (!taylor_refine(oct, s, r, c, dx, dy, ds)) continue;

          // Reject if offset too large (peak belongs to a different sample)
          if (std::abs(dx) > params.offset_max ||
              std::abs(dy) > params.offset_max ||
              std::abs(ds) > params.offset_max) continue;

          // Compute refined position
          double refined_r = r + dy;
          double refined_c = c + dx;
          double refined_s = s + ds;

          // Reject low contrast
          double contrast = std::abs(oct[s].at<float>(r, c)) +
                           0.5 * (  // first-order correction
                               (oct[s].at<float>(r, c + 1) - oct[s].at<float>(r, c - 1)) * 0.5 * dx +
                               (oct[s].at<float>(r + 1, c) - oct[s].at<float>(r - 1, c)) * 0.5 * dy +
                               (oct[s + 1].at<float>(r, c) - oct[s - 1].at<float>(r, c)) * 0.5 * ds);
          if (contrast < params.contrast_thresh) continue;

          // Edge rejection
          if (is_edge(oct, r, c, s, params.edge_ratio)) continue;

          // Convert to image coordinates
          KeyPoint kp;
          int octave = static_cast<int>(o);
          double sigma;
          octave_to_image_coords(octave, static_cast<int>(refined_s),
                                 refined_r, refined_c,
                                 dog.sigma0, dog.n_scales,
                                 kp.pt.x, kp.pt.y, sigma);

          kp.size = sigma;
          kp.response = contrast;
          kp.octave = octave;
          kp.angle = 0.0;  // Not computed here (Spiral 3 descriptor handles this)

          keypoints.push_back(kp);
        }
      }
    }
  }

  return keypoints;
}

}  // namespace meow::sfm
```

```cpp
  assert(!image.empty());

  auto gauss = build_gaussian_pyramid(image, 0, n_scales_, sigma0_);
```
